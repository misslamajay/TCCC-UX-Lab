# V3

## 变更说明

- 将机器人列表卡片中的操作文案由“编辑配置”统一调整为“编辑内容”，弱化参数配置心智，强化“继续完善已填内容”的任务语义。
- 调整编辑机器人入口的默认落点，进入编辑态后优先展示方案 1 的整合式单页表单，减少在双方案之间再次切换的操作成本。

## 交互优化

- 解决列表页操作按钮文案偏“配置项维护”、与当前单页编辑心智不完全一致的问题，改用“编辑内容”后，用户更容易理解这是对机器人内容与通知信息的继续编辑。
- 解决编辑已有机器人时默认落到方案 2、与当前主推方案不一致的问题，改为默认进入方案 1，缩短到达目标编辑界面的路径。

## 组件复用

- 延续复用自动推送现有的列表卡片、按钮、表单输入与双方案共用状态结构，本次未新增 Shared 公共组件。
- 保持与管理端既有控制台壳子和自动推送页面结构一致，避免因发布微调引入新的交互分支。

# V1

## 变更说明

- 新增“自动推送”功能入口与新手引导链路，完善从管理端菜单发现、气泡触达至首屏引导页的完整信息架构。
- 搭建自动推送首个可交互版本，覆盖机器人添加、编辑、测试、删除与列表管理等核心场景。

## 交互优化

- 解决新用户首次进入时难以发现功能入口的问题，通过 Agent 首页上新气泡与引导首页建立明确的体验入口。
- 解决自动推送首次配置路径不连贯的问题，将渠道选择、Webhook 配置、测试反馈与列表回填串联为闭环流程。

## 组件复用

- 复用控制台壳子与侧边导航结构，保持管理端信息架构与视觉样式一致。
- 复用 Button、Input、CheckBox、ConfirmDialog 等基础组件，降低新增功能的交互实现成本。

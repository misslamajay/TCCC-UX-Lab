# V1

## 变更说明

- 信息架构调整：任务详情由「多层表格钻取」重构为「左任务卡列表 + 右详情面板」的主从布局，去除中间表格层级，缩短任务浏览路径。
- 交互流程优化：右侧详情面板分为「指标看板 / 呼叫详情」二级页签，任务卡与详情实时联动。
- 状态驱动的操作体系：操作按钮按任务状态（待开始 / 进行中 / 已暂停 / 已完成 / 已结束 / 已终止）动态呈现「主操作 + 更多操作」，点击终止 / 暂停 / 继续可真实驱动状态流转，头部标签、任务卡标签、操作组、看板同步刷新。
- 任务生命周期动作补全：编辑任务进入编辑页（被叫名单置灰只读、标题对应任务名）、复制任务生成「原名-副本」、删除任务二次确认后移除。
- 导入号码能力：新增「文件上传 / 任务号码重呼（去重）」分段弹窗，接入状态列头可筛选（默认选中除「正常通话」外的全部异常状态并全选），支持导入到当前任务（跳转被叫未呼名单）与导入至新任务（被叫名单为选中号码、不可修改）。
- 呼叫详情下钻：呼叫明细表格行点击展开右侧通话详情抽屉（基础信息九宫格、AI 分析 / 通话流程 / 历史通话页签、底部音频栏与上下条切换）。

## 交互优化

- 任务浏览层级过深 → 主从布局一屏直达任务指标与呼叫明细。
- 操作按钮与任务状态脱节 → 状态机驱动操作可见性与流转结果，避免无效操作。
- 号码导入路径不清晰 → 分段弹窗统一「文件上传」与「历史号码重呼」，异常状态默认预选降低筛选成本。

## 组件复用

- 复用 tccc-new 规范的 PageContentWrapper、Button、Table、Tabs 与浅色控制台设计令牌，保持与管理端其余模块的视觉一致性。

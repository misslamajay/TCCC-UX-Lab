# V2

## 变更说明

- 操作与状态确认交互闭环：终止任务、删除任务均补齐二次确认弹窗，明确不可逆风险提示，降低误操作成本；统一收敛操作项，移除所有状态下的「导出数据 / 导出录音」冗余入口。
- 呼叫详情批量操作能力：呼叫记录表格引入复选框列（表头全选 + 行多选 + 半选态），支持进入多选后单击整行即选中而非唤起详情抽屉，批量操作栏收敛到工具栏右侧（导出数据 / 导出录音 / 取消选择），提升批量处理效率。
- 导入号码弹窗重构：分段 Tab 改为「新增呼叫号码 / 已有号码重呼」双单选卡片，按任务状态置灰对应卡片并附 hover 归因提示，弹窗自动定位到可用项；接入状态列头支持多选筛选（默认选中异常状态），底部操作栏吸底。
- 编辑态数据保护：编辑已有任务时被叫名单置灰不可改，并新增蓝色提示条引导用户改用「导入号码」补充号码；编辑页顶部标题与任务名对应。
- 任务卡与布局精修：任务卡改为白底、增大卡片间距、底部信息加分割线；去除任务详情外围留白使主从区贴边铺满；左侧筛选栏与右侧 Tab 分割线像素级对齐；看板标题与内容间距规范为 12px。

## 交互优化

- 高风险操作前置确认：终止 / 删除均需二次确认，避免不可逆误操作。
- 多选态语义清晰：一旦进入多选，整行点击即为选中操作，不再与「查看详情」冲突。
- 导入路径按状态收敛：待开始 / 进行中 / 已暂停禁用重呼，已完成 / 已结束禁用新增，并以 hover 提示解释原因，减少无效尝试。

## 组件复用

- 复用 tccc-new 规范的 ConsoleLayoutLight / PageContentWrapper / Table / Button 等基础组件；确认弹窗、导入弹窗通过 Portal 复用统一交互模式。

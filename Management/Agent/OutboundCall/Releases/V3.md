# V3

## 变更说明

- 新建任务流程升级为三步向导：配置基本信息 → 设置外呼时间 → 选择附加策略，竖向步骤条 + 完成态摘要，逐步展开，支持上一步/下一步返回。
- 外呼时间配置能力完善：时区选择、呼出起止时间（日历 + 时/分/秒精确选择，当前时间以前不可选、结束时间不早于开始）、呼出时段（日期支持法定工作日/周末/每天/自定义多选，时段可点击选择、可增删多时段，仅一条时删除置灰）。
- 附加策略配置：重呼策略（重呼次数、重复间隔上下限、触发条件分组多选）、话后策略（策略名称、接口配置弹窗、触发模式、触发条件），可按需勾选。
- 编辑态数据回填：编辑任务时基本信息与外呼时间必填项完整带入；「已结束」任务编辑时保留开始时间、清空结束时间以便重设续拨；创建按钮按来源区分「立即创建 / 保存内容」。
- 任务操作项规范：已结束/已完成任务操作为「编辑任务 / 复制任务 / 导入号码」+ 更多「删除任务」。
- 呼叫详情表格增强：已呼/未呼名单表头补半选态；批量操作（导出数据/导出录音，未呼名单为导出号码/删除号码，删除二次确认）；导出成功 toast；未呼名单字段调整为序号/主叫/被叫/name/age/删除号码。
- 视觉细节：指标看板漏斗配色改为青绿/墨绿/黑；创建流程完成后返回任务详情看板/详情页。
- 修复：从首页空状态进入创建时，「立即创建 / 保存内容」提交后固定进入任务详情，不再误返回首页空状态（提交动作与顶部返回动作解耦）。

## 交互优化

- 高风险与到期场景前置引导：删除/终止二次确认；已结束任务编辑强制重设结束时间。
- 时间选择全面可点选、精确到秒，杜绝手输格式错误。
- 编辑复用创建流程并回填历史配置，减少重复录入。

## 组件复用

- 复用 tccc-new 规范的 ConsoleLayoutLight / PageContentWrapper / Table / Button / MultiSelect / DropdownList；确认弹窗、接口配置弹窗、Toast 经 Portal 统一交互模式。

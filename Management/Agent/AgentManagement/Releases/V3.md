# V3

## 变更说明

- 批量操作能力增强：智能体列表新增表头全选、行多选与批量移动，支持一次调整多个智能体的项目归属
- 项目归属模型升级：智能体详情页新增“所属项目”多选下拉，支持同一智能体同时归属多个项目
- 状态反馈与视觉稳定性优化：批量移动完成后展示成功 Toast，详情顶栏控件保持单行并避免内容挤压

## 交互优化

- 逐条调整项目归属 → 选中多个智能体后统一批量移动，缩短重复操作路径
- 单一项目限制 → 在详情页直接维护多个所属项目，适配跨项目复用场景
- 操作完成状态不明确 → 增加“移动成功”即时反馈，降低结果确认成本
- 窄屏下控件内容换行 → 为顶栏操作区设置稳定宽度与单行约束，保持信息可读性

## 组件复用

- 复用 `Button`、`Input`、`CheckBox` 等项目公共组件，保持列表操作和表单控件的一致性
- 沿用现有弹窗、下拉菜单与 Toast 视觉规范，减少新增交互的学习成本

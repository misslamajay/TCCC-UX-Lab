# V1

## 变更说明

- 建立角色管理的完整操作闭环，覆盖角色列表、创建、编辑、详情查看、删除确认与状态反馈。
- 将角色授权重构为模块、页面访问、操作权限与资源范围四层模型，提升权限配置的可理解性与可控性。
- 统一列表、详情与编辑页的数据映射，保证角色名称、描述、成员数量、邮箱、权限和资源范围一致。
- 发布修复：将完整 Vite SPA 改为可在 GitHub Pages 子目录独立运行的静态页面，所有图片与图标使用相对路径，避免根路径资源 404。

## 交互优化

- 新增未保存内容离开确认，区分创建态与编辑态，避免误操作导致数据丢失。
- 完善页面权限与操作权限的依赖关系、批量开启逻辑及禁用状态表达。
- 成员详情默认展示两行，超出后支持展开与收起，并确保展开数量与角色成员总数一致。
- 创建角色后自动回到列表并置顶展示，编辑时回填创建阶段的完整数据。

## 组件复用

- 复用 TCCC 浅色控制台的 `ConsoleLayoutLight`、`SideNavLight`、`PageContentWrapper`。
- 复用 `Button`、`Input`、`Tabs`、`Table` 等项目公共组件，并遵循统一的黑灰色设计令牌与交互状态。

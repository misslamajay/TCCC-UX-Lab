# V1

## 变更说明

- 新增 TCCC Web SDK 电话工作台独立发布版本，统一电话条、IM 与电话 + IM 组合入口的信息架构和视觉语言。
- 完善通话中、咨询、共同通话、转接、自助服务、话后处理等关键状态，提升多任务场景下的状态可识别性。
- 按 TCCC 2026 浅色规范统一间距、颜色、按钮、列表状态、Tooltip 与浮层表现。

## 交互优化

- 建立完整通话与咨询状态机，保持客户、咨询对象及语音识别状态连续，减少状态切换中的信息丢失。
- 优化输入号码、自助服务、转接、通讯录等浮层的定位与裁切避让，确保独立电话条和组合工作区均可完整操作。
- 修正在线/离线会话、ASR 双栏与纵向布局、通话卡片高度和内容间距，避免页面跳动、遮挡与布局挤压。

## 组件复用

- 本版本为自包含 HTML 交互原型，未直接引用 `Shared/` 公共组件；视觉和交互状态遵循 TCCC 2026 规范。

# Annotation - 标注 Prompt 模板

TCCC 会话标注场景下的 Prompt 设计规范。

## 标注类型

| 类型 | 说明 | Prompt 要点 |
|------|------|-------------|
| 意图标注 | 识别用户意图分类 | 分类体系 + 边界定义 + 置信度阈值 |
| 情感标注 | 识别用户情绪状态 | 情感维度定义 + 程度分级 |
| 质检标注 | 服务质量评估 | 评分维度 + 合规规则 + 扣分项 |
| 实体标注 | 提取关键实体 | 实体类型定义 + 归一化规则 |

## Prompt 结构

```
[System]
你是 TCCC 会话标注助手。根据以下规则对会话内容进行标注。

[Rules]
- 标注维度：{dimensions}
- 分类体系：{taxonomy}
- 置信度阈值：{threshold}
- 输出格式：JSON

[Context]
会话内容：{conversation}
元数据：{metadata}

[Instruction]
请对上述会话进行标注，输出格式如下：
{output_schema}
```

## 质检标注示例

```
评分维度：
1. 服务态度（1-5分）：是否礼貌、耐心
2. 问题解决（1-5分）：是否有效解决用户问题
3. 流程规范（1-5分）：是否遵循服务流程
4. 信息准确（1-5分）：提供的信息是否准确

输出格式：
{
  "scores": { "attitude": 5, "resolution": 4, "compliance": 5, "accuracy": 4 },
  "issues": ["未主动告知退款时效"],
  "highlights": ["情绪安抚得当"]
}
```

# KnowledgeBase - 知识库 Prompt 模板

TCCC 知识库场景下的 Prompt 设计规范。

## 知识库类型

| 类型 | 说明 | 典型用途 |
|------|------|----------|
| FAQ | 问答对 | 常见问题自动回复 |
| 文档库 | 结构化文档 | 产品文档、政策法规 |
| 网页爬取 | 自动同步 | 官网内容更新 |

## 检索增强 (RAG) Prompt 结构

```
[System]
你是 TCCC 知识助手。基于以下检索结果回答用户问题。

[Rules]
- 仅基于提供的检索结果回答，不编造信息
- 如果检索结果不包含答案，明确告知用户
- 引用来源时标注文档名称和段落
- 回答使用清晰的分段结构

[Retrieved Context]
{chunks_with_metadata}

[User Question]
{question}

[Instruction]
基于以上检索结果，回答用户问题。格式：
1. 直接回答
2. 引用来源
3. 相关补充（如有）
```

## 知识库管理 Prompt

| 操作 | Prompt 要点 |
|------|-------------|
| 知识切片 | 切片策略、最大长度、重叠窗口 |
| 知识去重 | 相似度阈值、去重策略 |
| 知识更新 | 增量索引、版本管理 |
| 质量评估 | 覆盖率、准确性、时效性 |

# Agent - 智能体 Prompt 模板

TCCC 智能体场景下的 Prompt 设计规范与模板。

## 设计原则

1. **角色明确**：每个 Agent 有清晰的角色定义与能力边界
2. **上下文可控**：通过 System Prompt 限定回答范围，避免幻觉
3. **多轮对话管理**：维护会话状态，支持上下文引用
4. **安全边界**：敏感信息脱敏，防止 Prompt 注入

## Prompt 结构

```
[System]
角色定义 | 能力范围 | 行为约束 | 输出格式

[Context]
业务数据 | 用户信息 | 会话历史摘要

[Instruction]
当前任务 | 期望输出 | 特殊规则

[Examples]
Few-shot 示例（可选）
```

## 智能体类型

| 类型 | 典型场景 | Prompt 特点 |
|------|----------|-------------|
| 客服智能体 | 咨询、售后 | 话术规范、情绪识别、转人工策略 |
| 知识问答 | 内部知识查询 | 检索增强、引用溯源、置信度标注 |
| 外呼智能体 | 回访、通知 | 流程驱动、TTS 优化、意图识别 |
| 辅助智能体 | 坐席辅助 | 实时建议、知识推荐、话术提示 |

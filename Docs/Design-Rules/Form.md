# Form - 表单规范

TCCC 控制台表单设计规范，覆盖新建、编辑与批量操作场景。

## 布局模式

| 模式 | 适用场景 | 特点 |
|------|----------|------|
| 水平表单 | 筛选条件、搜索 | 标签与输入框同行 |
| 垂直表单 | 新建/编辑弹窗、抽屉 | 标签在上，输入框在下 |
| 分步表单 | 复杂配置（创建智能体等） | 步骤条引导 |
| 内联编辑 | 表格行内快速编辑 | 点击即编辑 |

## 表单项规范

### 必填与选填

- 必填项用红色 `*` 标注在标签前
- 选填项不标注，或用灰色 `(选填)` 提示
- 同一表单中大部分为必填时，仅标注选填项

### 校验规则

| 触发时机 | 规则 |
|----------|------|
| 输入时 | 格式校验（手机号、邮箱等） |
| 失焦时 | 非空、长度、格式校验 |
| 提交时 | 关联校验、异步校验（唯一性等） |

### 错误提示

- 在输入框下方显示，红色文字
- 错误信息需明确：说明问题 + 建议修正方式
- 同一表单滚动到第一个错误项

## 表单操作

- **主操作**：蓝色按钮，右侧
- **次操作**：灰色按钮，左侧
- **危险操作**：红色按钮，需二次确认
- **取消**：关闭当前弹窗/抽屉，有修改时提示保存

## 分步表单

- 顶部步骤条，显示当前步骤、已完成步骤、待完成步骤
- 每步完成后才能进入下一步
- 支持返回上一步修改
- 最后一步为确认页，展示所有填写内容

# Interaction - 交互规范

TCCC 控制台交互设计规范。

## 反馈层级

| 层级 | 组件 | 适用场景 | 持续时间 |
|------|------|----------|----------|
| 轻提示 | Toast | 操作成功/失败 | 2-3s 自动消失 |
| 中提示 | Notification | 异步任务完成、系统通知 | 需手动关闭 |
| 重提示 | Modal | 删除确认、不可逆操作 | 需手动操作 |
| 内联提示 | Alert | 页面级提示、配置说明 | 常驻或可关闭 |

## 加载状态

| 场景 | 方案 |
|------|------|
| 页面首次加载 | 骨架屏 |
| 局部数据刷新 | Spin + 内容区半透明遮罩 |
| 按钮操作 | 按钮 Loading 状态，禁止重复点击 |
| 长时任务 | 进度条 + 后台执行提示 |

## 动效规范

| 类型 | 时长 | 曲线 |
|------|------|------|
| 微交互（hover、选中） | 150ms | ease-out |
| 过渡（展开/收起） | 250ms | ease-in-out |
| 页面切换 | 300ms | ease-in-out |
| 大面积重排 | 400ms | cubic-bezier(0.4, 0, 0.2, 1) |

## 拖拽

- 拖拽手柄区域显示 `⋮⋮` 图标
- 拖拽中：源位置留虚线占位，目标位置显示蓝色插入线
- 拖拽结束：动画归位

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + K` | 全局搜索 |
| `Esc` | 关闭弹窗/抽屉/下拉 |
| `Enter` | 确认弹窗 |
| `Ctrl/Cmd + S` | 保存（编辑页面） |

## 空状态与异常

- **无数据**：EmptyState 组件 + 引导操作按钮
- **无权限**：403 提示 + 申请权限入口
- **网络异常**：断网提示 + 重试按钮
- **服务异常**：500 提示 + 联系支持入口

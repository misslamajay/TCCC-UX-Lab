# Table - 表格规范

TCCC 控制台表格设计规范，覆盖数据展示、排序、筛选与交互。

## 基本结构

```
┌──────────────────────────────────────────────┐
│  筛选条件区 (FilterPanel)                      │
├──────────────────────────────────────────────┤
│  批量操作区 │ 搜索 │ 视图切换 │ 自定义列       │
├──────────────────────────────────────────────┤
│  ☐ │ 列1 ▲ │ 列2 │ 列3 │ ... │ 操作         │
│  ☐ │ data  │ data│ data │ ... │ 编辑 删除    │
│  ☐ │ data  │ data│ data │ ... │ 编辑 删除    │
├──────────────────────────────────────────────┤
│  共 N 条  │ < 1 2 3 ... > │ 每页 ▼          │
└──────────────────────────────────────────────┘
```

## 列宽规范

| 列类型 | 宽度 | 说明 |
|--------|------|------|
| 复选框 | 40px | 固定 |
| 序号 | 56px | 固定 |
| 标签/状态 | 80-120px | 根据内容 |
| 标准文本 | 160-240px | 自适应 |
| 长文本 | 截断 + Tooltip | max-width 280px |
| 操作列 | 按钮数 × 56px | 固定右侧 |

## 交互规则

- **排序**：点击列头切换升序/降序/默认，单列排序
- **筛选**：列头筛选仅用于枚举型字段（状态、类型），复杂筛选走 FilterPanel
- **行选择**：支持全选（当前页）、跨页全选、反选
- **行展开**：点击展开箭头查看详情，不影响同行操作
- **空状态**：使用 EmptyState 组件，区分"无数据"和"无权限"
- **加载**：骨架屏 > Spin，数据更新时保持表格结构不变

## 分页

- 默认每页 20 条，可选 10/20/50/100
- 数据量 < 100 时可使用滚动加载替代分页
- 超过 1000 条时必须使用服务端分页

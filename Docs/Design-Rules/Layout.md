# Layout - 布局规范

TCCC 控制台布局体系，基于腾讯云 Console Layout 标准。

## 整体布局

```
┌─────────────────────────────────────────────┐
│                  TopNav                      │
├──────┬──────────────────────────────────────┤
│      │              PageHeader               │
│ Side ├──────────────────────────────────────┤
│ Nav  │                                      │
│      │             Content                   │
│      │                                      │
└──────┴──────────────────────────────────────┘
```

## 尺寸规范

| 区域 | 宽度 | 说明 |
|------|------|------|
| SideNav 折叠 | 56px | 仅图标 |
| SideNav 展开 | 200px | 图标 + 文字 |
| TopNav 高度 | 48px | 固定顶部 |
| PageHeader | 自适应 | 面包屑 + 标题 + 操作区 |
| Content 区域 | 剩余宽度 | 最小宽度 960px |

## 栅格系统

- 24 栏栅格，间距 8px
- 页面内容区左右 padding：24px
- 卡片间距：16px

## 响应式断点

| 断点 | 宽度 | 行为 |
|------|------|------|
| xs | < 768px | 不支持，提示使用桌面端 |
| sm | 768px - 1024px | SideNav 折叠 |
| md | 1024px - 1440px | SideNav 展开 |
| lg | > 1440px | 内容区最大宽度 1440px 居中 |

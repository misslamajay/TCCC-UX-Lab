# Console - 信息架构

控制台（Console）面向平台运维与租户管理员，提供租户管理、计费、监控与全局配置能力。

## 模块划分

| 模块 | 职责 | 核心页面 |
|------|------|----------|
| Tenant | 租户管理 | 租户列表、租户详情、开通/停用 |
| Billing | 计费管理 | 账单、用量统计、套餐管理 |
| Monitor | 系统监控 | 健康状态、告警、日志 |
| Config | 全局配置 | 系统参数、权限模板、集成配置 |
| Experiments | 实验性功能 | 探索性运维与配置原型 |

## 导航层级

```
控制台
├── 租户 (Tenant)
├── 计费 (Billing)
├── 监控 (Monitor)
├── 配置 (Config)
└── 实验室 (Experiments)
```

## 角色权限

- **平台管理员**：全部功能
- **财务**：Billing 只读 + 导出
- **运维**：Monitor + Config
- **租户管理员（自助入口）**：Tenant 自身详情 + Billing 自身账单

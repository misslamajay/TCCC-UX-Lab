# Management - 信息架构

管理端（Management）面向企业管理员与运营人员，提供 TCCC 全产品线的配置、监控与管理能力。

## 模块划分

| 模块 | 职责 | 核心页面 |
|------|------|----------|
| Overview | 运营总览与关键指标 | 服务记录、号码管理、AI 会话分析 |
| Extension | 扩展能力集成 | 扩展中心 |
| Agent | 智能体管理 | 智能体管理、知识库、外呼任务 |
| Staff | 坐席与客服管理 | 仪表盘、在线/电话/音视频客服、通用设置、客服管理 |
| Experiments | 实验性功能与交互探索 | Agent 卡片布局、仪表盘探索、标注探索、知识探索、工作流探索 |

## 导航层级

```
管理端
├── 总览 (Overview)
├── 智能体 (Agent)
├── 坐席管理 (Staff)
├── 扩展 (Extension)
└── 实验室 (Experiments)
```

## 角色权限

- **超级管理员**：全部功能
- **运营管理员**：Overview + Agent + Staff（不含敏感配置）
- **坐席组长**：Staff 模块 + 本组数据
- **只读审计**：全部页面只读权限
